# Violentmonkey CSS / Discord userscripts

PC移行時に復元するための、Discord用Violentmonkeyユーザースクリプト2本です。JavaScriptからCSSを追加します。スクリプトは提供された内容をそのまま保存しています。

## 保存したスクリプト

- [自分の投稿だけ赤バブル](discord-red-bubbles.user.js)：表示名が `moruku36` の投稿を赤いバブル・白文字で表示します。
- [DM欄を折りたたむ](discord-collapse-dm.user.js)：DM画面の一覧とユーザー設定パネルを折りたたみ、チャットの横幅を広げます。サーバーアイコン列は残します。

## 新しいPCで復元する

1. 使用するブラウザの公式拡張機能ストアから **Violentmonkey** をインストールします。
2. 上の各ファイルを開き、GitHubの **Raw** でソース全文を表示します。
3. Violentmonkeyのダッシュボードで新規スクリプトを作り、雛形をすべて消してソース全文を貼り付け、保存します。2本は別々のスクリプトとして保存してください。
4. 両方のスクリプトを有効にして、ブラウザ版Discordを開き直すか再読み込みします。
5. 自分の投稿の色と、DM画面左下の「DM表示／DM隠す」ボタンを確認します。

Raw表示時にViolentmonkeyのインストール画面が開いた場合は、内容を確認してその画面からインストールしても構いません。

## 使い方・注意点

- 対象は `https://discord.com/*` のブラウザ版です。Discordデスクトップアプリには適用されません。
- 赤バブルの `const ME = 'moruku36';` はメッセージに表示される名前に合わせる設定です。表示名を変更した場合はこの値を変更してください。ユーザーIDではなく表示名で判定します。
- DM欄は初期状態で折りたたまれます。「DM表示」で一覧とユーザー設定を戻せます。Violentmonkeyのスクリプトメニュー「DM一覧の表示／非表示」からも切り替えられます。
- 開閉状態はViolentmonkeyのスクリプト用ストレージに保存され、同じブラウザでの再読み込み後も続きます。このリポジトリには以前の開閉状態やブラウザ設定は含まれないため、新しいPCでは初期状態から始まります。
- 元に戻す場合は該当スクリプトを無効にしてDiscordを再読み込みしてください。
- Discordの画面構造・クラス名が変更されると効かなくなる可能性があります。
- 保存対象はソースコードと復元手順のみです。認証情報、トークン、メッセージ履歴、ブラウザのプロファイルは含めていません。

## 確認

2本とも `node --check` によるJavaScript構文検査に合格しています。これはブラウザでの表示動作や将来のDiscordへの互換性を保証するものではありません。
